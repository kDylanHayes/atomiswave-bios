# Atomiswave BIOS

Ghidra pseudocode for the Sammy Atomiswave (SYSTEM X) SH-4 boot flash, IC23.

`decomp/bios0/functions` is bios0. `decomp/bios0/index.txt` lists each function. bios1 matches those bytes except six footer bytes, also listed in the index.

The ROM images are not in this repo. The C is decompiler output, not rebuilt source.
